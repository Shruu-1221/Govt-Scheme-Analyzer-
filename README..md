# **Government Scheme Assistant**



##### **Project Description**

The Government Scheme Assistant is a Python-based application that helps students find suitable government scholarship schemes based on their eligibility criteria. It provides information about scheme benefits, required documents, and eligibility requirements.

##### 

##### **Objectives**

\- To develop a simple Python-based Government Scheme Assistant.

\- To help students find schemes according to their profiles and requirements.

\- To provide eligibility criteria, benefits, and required documents.

\- To reduce the time and effort required to search for government schemes.



##### **Features**

\- Student eligibility checking.

\- Government scholarship scheme information.

\- Scheme benefits and required documents.

\- Reasons for ineligibility.

\- MySQL database integration.



##### **Technologies Used**

\- Python

\- MySQL

\- XAMPP

\- Tkinter 

\- MySQL Connector for Python

##### 

##### **Project Files**

\- `main.py` – Main application.

\- `analyzer.py` – Checks scheme eligibility.

\- `database.sql` – Database structure and sample data.

\- `requirements.txt` – Required Python package.

##### 

##### **Requirements**

\- Python installed on your computer.

\- XAMPP with MySQL/MariaDB.

\- The MySQL Connector Python package.



##### **Installation and Execution**

1\. Install Python and XAMPP.

2\. Start MySQL from the XAMPP Control Panel.

3\. Open phpMyAdmin.

4\. Import `database.sql` to create the database and tables.

5\. Open a terminal in the project folder.

6\. Install dependencies using `pip install -r requirements.txt`.

7\. Check the database connection settings in your Python files.

8\. Run the application using `python main.py`.



##### **Future Scope**

The project can be enhanced with an AI-powered assistant, more government schemes, automatic updates, and online application links.



##### **Conclusion**

The Government Scheme Assistant makes it easier for students to discover suitable scholarship schemes and understand their eligibility requirements.
